# REGARD

> 看見影像的本質，定義更高的標準。

本機優先的影片審片工具。在瀏覽器載入影片，於時間點標記修改、截圖標註、附上參考，再匯出 PDF / Excel 報告。所有處理都在你的電腦本機完成，**影片不上傳、不經過任何伺服器**。

[English](./README.en.md)

## 使用方式

1. 開啟網址 [REGARD](https://kane1a.github.io/REGARD/regard.html)
2. 點「開啟影片」載入本機影片。
3. 播放到需要修改的位置，點「加入修改」標記時間點，填寫說明、選擇嚴重度（必須修改 / 建議修改 / 僅提醒）。
4. 需要畫面證據時，使用截圖與標註工具圈出問題處。
5. 填寫專案名稱，點「匯出」產生 PDF 或 Excel 報告（也支援中英介面切換）。

修改紀錄會自動暫存在瀏覽器本機；不小心關掉頁面時，重新開啟同一支影片即可恢復。本工具為電腦版介面設計，建議視窗寬度 1024px 以上。

### 快捷鍵

| 按鍵 | 功能 |
|---|---|
| `Space` | 播放 / 暫停 |
| `←` `→` | 往後 / 往前 5 秒 |
| `,` `.` | 上一格 / 下一格 |
| `J` `K` `L` | 倒退 1 秒 / 暫停 / 播放（連按加速） |
| `[` `]` | 跳到上一個 / 下一個修改點 |
| `M` | 在此時間點加入修改 |
| `?` | 顯示全部快捷鍵 |
