# 凝視 REGARD

> 看見影像的本質，定義更高的標準。

本機優先的影片審片工具。在瀏覽器載入影片，於時間點標記修改、截圖標註、附上參考，再匯出精緻的 PDF / Excel 報告。所有處理都在你的電腦本機完成，**影片不上傳、不經過任何伺服器**。

[English](./README.en.md)

## 使用方式 Usage

1. 開啟網址 `https://<你的帳號>.github.io/<專案名>/regard.html`（部署後）。
2. 點「開啟影片」載入本機影片。
3. 播放到需要修改的位置，點「加入修改」標記時間點，填寫說明、選擇嚴重度（必須修改 / 建議修改 / 僅提醒）。
4. 需要畫面證據時，使用截圖與標註工具圈出問題處。
5. 填寫專案名稱，點「匯出」產生 PDF 或 Excel 報告（也支援中英介面切換）。
